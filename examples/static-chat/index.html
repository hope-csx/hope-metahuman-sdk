HOPE Metahuman Service

Static embed example

Audio and microphone access start only when you press the start button — browsers require a real interaction before a page may play sound.

Connection

Credential
Local development only. This exchanges the key in the browser so you can try the SDK without writing a backend first, and it refreshes itself as tokens expire. The secret is typed here at runtime and never persisted — but a secret does not expire, so a page that carries one hands every visitor permanent access to your tenant. Before you deploy anything, move the exchange to a server: see examples/token-server.

Everything except the token is saved in this browser's local storage so you do not have to retype it.
